# multi-agent-rlm
Proof-of-Concept multi-agent & multi-LLM command line tool using RLM technique for multi-agent systems. Currently focussed on PDF Document ingestion and conversion to Markdown using the docling library. RLM Agent interaction with the converted Markdown. The tool is built using the fan-out method of orchestrator-worker agents to traverse documents, summarise and store them in a local database/ short term memory (currently stored locally) instead of injecting the output to the prompts. This tool can be bolted to any frontend and data layer for a plug and play RLM solution.
